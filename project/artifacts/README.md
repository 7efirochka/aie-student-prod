# Артефакты проекта

В этой папке хранятся **артефакты**, генерируемые в процессе работы проекта:

- **Обученные модели** — сериализованные объекты, файлы весов (`.pkl`, `.joblib`, `.h5`, `.pt`)
- **Метрики и отчёты** — результаты экспериментов в формате `.json` / `.csv`
- **Визуализации** — графики, диаграммы (`.png`, `.jpg`, `.pdf`, `.svg`)
- **Логи экспериментов** — небольшие текстовые файлы с историей обучения

Доступные артефакты:

  - `cosine_description_matrix.npy` - матрица косинусного сходства (описания)
  - `cosine_hybrid_matrix.npy` - матрица косинусного сходства (гибридная)
  - `encoders.joblib` - сериализованные энкодеры 
  - `compare_models.json` - результаты сравнения моделей 
  - `genres_distribution.png` - диаграмма распределение жанров 


Рекомендуется:

- не хранить здесь **слишком крупные** файлы (гигабайты логов или моделей);
- при необходимости крупных файлов:
  - использовать внешнее хранилище;
  - в этом репозитории хранить только ссылки или небольшие версии моделей/результатов.
